# DotGrid

近战范围内「带着我的 debuff 的怪」占几只 —— 用**长度的比例**代替数字。

> 12.x 起，战斗中的光环数据对插件不可读，所以"带 DoT 的怪占几成"没法用数字表达。
> DotGrid 的答案：**每只怪占一段，条的长度就是怪数，红掉的那截就是比例** —— 用眼睛读长度。

## 特性

- 进度条 / 格子两种显示方式，长度始终跟随怪数（几只怪就几段，不画空段）
- 最多 4 个 debuff 同时监控：全部具备才变红，或任一命中即变红
- 三档外观：自绘纯色块 / 经典面板风 / 原生名字板风
- 直接拖拽定位、设置界面实时预览、全部命令都能在界面里点出来
- 账号级配置档：多角色各自一套，可随时新建 / 切换 / 删除
- 不依赖任何第三方库，不使用任何 Blizzard 界面模板，不新增任何贴图
- 附带离线冒烟测试（自带 Lua 桩 + 三百余项检查），不需要进游戏即可验证

## 安装

1. 解压得到 `DotGrid` 文件夹
2. 放进 `<魔兽世界安装目录>/_retail_/Interface/AddOns/`
3. 重启客户端，在插件列表里确认 DotGrid 已勾选

## 快速开始

```
/dg spell 1943,703      设置要监控的 debuff（法术 ID，逗号/空格分开，最多 4 个）
/dg unlock              解锁：显示区变成可抓的黄框，拖到想要的位置
/dg lock                锁回（位置自动存进存档）
/dg bar min 1           想连一只怪也显示
/dg                     打开图形化设置界面（再按一次关闭；Esc 也能关）
```

没设置法术时插件处于**待机**：不采集、不运算、不显示任何东西 —— 先 `/dg spell` 再战斗。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/dg` | 打开图形化设置界面（=`/dg config` / `ui` / `options`，再按一次关闭） |
| `/dg help` | 全部命令 + 当前状态（版本 / 方式 / 法术 / 口径 / 位置） |
| `/dg on` / `off` | 启用 / 禁用 |
| `/dg mode bar` / `grid` | 显示方式：进度条（默认）/ 格子 |
| `/dg style solid` / `panel` / `nameplate` | 外观：纯色块（默认）/ 经典面板风 / 原生名字板风 |

**进度条**

| 命令 | 说明 |
| --- | --- |
| `/dg bar segw 21` | 每段宽 6–60（总长 = 怪数 × (段宽+缝) − 缝） |
| `/dg bar min 2` | 少于这么多只怪就不显示整条（`1` = 一只怪也显示） |
| `/dg bar height 20` | 条高 6–80 |
| `/dg bar gap 1` | 段间距 0–10 |
| `/dg bar ticks on` / `off` | 段间 1px 刻度线（默认开） |

**位置**

| 命令 | 说明 |
| --- | --- |
| `/dg unlock` / `lock` | 解锁拖动 / 锁回 |
| `/dg pos` | 看当前位置 |
| `/dg pos 800 500` | 直接设位置（x y，相对屏幕左下角） |
| `/dg pos center` | 回到屏幕中左默认位置 |

**监控哪些 debuff**（只支持法术 ID，最多 4 个）

| 命令 | 说明 |
| --- | --- |
| `/dg spell 1943,703` | 设置监控列表（逗号/空格分开） |
| `/dg spell clear` | 清空 ⇒ 插件回到待机 |
| `/dg spells` | 看当前监控了哪几个 + 多 debuff 语义 |
| `/dg spells all` / `any` | `all` = 全部具备才变红（默认，按法术切横条）/ `any` = 任一命中就变红 |

**范围与口径**

| 命令 | 说明 |
| --- | --- |
| `/dg yards 11` | 精确距离上限（码）；副本内自动退回档位；`0` = 只靠档位 |
| `/dg tier 2` / `3` / `0` | 档位兜底：`2`=8码、`3`=7码；`0` = 不判距（范围最大） |
| `/dg engaged combat` / `threat` / `all` | 统计范围：已进战斗（默认）/ 正在跟我打 / 范围内全算 |
| `/dg engaged on` / `off` | 等价写法：`on`=combat，`off`=all |
| `/dg combat on` / `off` | 只在你自己战斗中显示（默认开） |

**格子模式**

| 命令 | 说明 |
| --- | --- |
| `/dg size 18x18` | 方块尺寸 |
| `/dg perrow 5` | 每行方块数 |
| `/dg gap 4` | 方块间距 |

**颜色与透明度**

| 命令 | 说明 |
| --- | --- |
| `/dg color hit d80f0fff` | 命中（红段 / 红格）颜色，末两位是透明度 |
| `/dg color mob ffffffff` | 有怪、没我的 DoT 的颜色 |
| `/dg color empty ffffff2e` | 底槽 / 空槽位颜色 |
| `/dg color miss ffffffff` | 格子模式：有怪、没我的 DoT 的颜色 |
| `/dg alpha 50` | 一键：命中 / 有怪段 / 格子 = 50%（底槽不动） |
| `/dg alpha hit 50` | 单个：`hit` / `mob` / `miss` / `empty`，0–100 |

**配置档**

| 命令 | 说明 |
| --- | --- |
| `/dg profile` | 列出所有档（标出本角色在用哪个、几个角色在用） |
| `/dg profile new <名字>` | 用当前设置新建一个档并切过去 |
| `/dg profile load <名字>` | 本角色切到这个档 |
| `/dg profile save` | 把当前设置写回当前档 |
| `/dg profile delete <名字>` | 删档（「默认」和正在用的档不许删） |
| `/dg reset` | 恢复出厂（只清当前档，其它档不动） |

**诊断**

| 命令 | 说明 |
| --- | --- |
| `/dg diag` | 环境自检：几何、范围判定与原始返回值、逐只状态、界面状态 |
| `/dg verify` | 脱战真值核验：逐只打印命中情况与段号，用来对照红段 |
| `/dg debug on` / `off` | 调试输出 |

老版本的固定长度进度条、饼图模式与数量数字标签已移除；对应的旧命令（`bar fixed`、
`bar width`、`label`、`mode pie` 等）只会回一句提示，不再改动任何状态。

## 设置界面

`/dg` 打开。窗口可拖动（位置记在存盘里），八个标签页：

| 页面 | 内容 |
| --- | --- |
| 常规 | 预览画布 / 启用开关 / 显示方式 / 外观 / 只在战斗中显示 / 解锁·锁定 / 位置滑条 |
| 监控 debuff | 法术 ID 的添加与删除、多 debuff 语义单选、"清空（待机）" |
| 进度条 | 预览画布 / 段宽 / 条高 / 段间距 / 最少只数 / 刻度线 |
| 格子 | 预览画布 / 方块宽高 / 每行个数 / 间距 |
| 颜色 | 预览画布 / 四条透明度滑条（拖动即时预览）/ 四个色块 |
| 范围/口径 | 统计范围 / 精确码数上限 / 档位兜底 |
| 工具/诊断 | 环境自检 / 真值核验 / 恢复出厂 / 打印命令帮助 / 调试输出 |
| 配置档 | 当前档 / 保存到本档 / 删除本档 / 档名输入框 / 新建 / 加载 / 档列表 |

界面里没有任何自己的逻辑：每个控件的结果都拼成一条命令交给 `/dg` 执行，聊天框会回显
等价的命令 —— 命令行能做的界面上都有，两边不会出现行为差异。

## 显示与外观

**进度条**（`/dg mode bar`，默认）：每只怪一段，段宽 `bar segw`（默认 21）、缝 `bar gap`（默认 1）、
高 `bar height`（默认 20）；总长 = 怪数 × (段宽+缝) − 缝。怪特别多时（超过 900 像素）段宽自动
压细（下限 4 像素），一只怪都不会丢。

**格子**（`/dg mode grid`）：每只怪一个方块（默认 18×18，每行 5 个）。

**外观**（`/dg style`）：

| 档位 | 说明 |
| --- | --- |
| `solid`（默认） | 条 / 格 / 底槽 / 描边全部自绘，不用任何贴图 |
| `panel` | 整块套游戏自带的提示框面板，块面填充改用游戏自带的条纹理（白→灰渐变） |
| `nameplate` | 框用提示框边料染成金色，块面填充改用名字板血条纹理 |

带框的两档里，自绘的那圈 1px 描边会自动收掉（避免与原生边框叠成双线）。用到的都是
客户端自带资源：`Interface\Tooltips\UI-Tooltip-Background`、`Interface\Tooltips\UI-Tooltip-Border`、
`Interface\Tooltips\Nameplate-Border`、`Interface\TargetingFrame\UI-StatusBar`、
`Interface\TargetingFrame\NameplateFill`。

配色与透明度：命中（红）默认 `#d80f0f`、有怪段与格子默认纯白、底槽默认白 18%；
外圈描边固定黑 55%、段间刻度线固定黑 60%。四条透明度滑条可单独调（0–100%）。

## 范围与口径

客户端给插件的距离只有两套，没有"11 码"这一档：

| 判据 | 说明 |
| --- | --- |
| `UnitDistanceSquared` | 唯一能给真实码数的接口；副本 / 竞技场 / 战场内受限，此时自动退回档位 |
| `CheckInteractDistance` | 只有固定几档：`1`=28码、`2`=8码、`3`=7码、`4`=28码、`5`=7码 |

两个判据是"取更严"的关系，所以默认的 `/dg yards 11` + `/dg tier 2` 实际口径是 8 码。
想让范围更小：`/dg yards 5`（比档位细）、`/dg tier 3`、或 `/dg engaged threat`（通常最有效）。
`/dg yards 0` = 只用档位；`/dg tier 0` = 完全不判距（范围等于名字板可见范围）。

统计范围：`combat` 只要它在战斗中就算（默认）；`threat` 必须正在跟我 / 我队伍打
（`UnitThreatSituation`，副本内受限时单只怪自动退回"在战斗中"判定）；`all` 范围内全算。
"名字板最多显示多远"是客户端 CVar，与插件判定无关：`/console nameplateMaxDistance 10`。

## 配置档与多角色

存档是账号级的（`DotGridDB`），里面是 `profiles[档名]` 与 `charProfile[角色]`。

没指定过档的角色，第一次加载会得到一份以自己名字命名的**空档** —— 不继承「默认」档，
也就不继承别人设置的法术，因此在设置 debuff 之前插件完全不动。升级到本版本时在场的
角色例外：旧配置会被搬进「默认」档并由它接管，所以老用户的设置不会丢。

读 = 当前档 ∪ 出厂默认；写 = 一律写进当前档。想给某个角色单独一套：`/dg profile new 名字`。

## 诊断

```
/dg diag      环境自检：显示方式与几何 / 范围判定与原始返回值 / 逐只怪的 atk·dead·inCombat·
              仇恨·距离·档位 / 每段坐标与客户端贴图 / 界面状态
/dg verify    脱战真值核验：脱战时光环可读，逐只打印命中情况与段号，用来对照红段
/dg debug on  打开调试输出（[DBG] / [A] / [1] / [2] / [3] 前缀）
```

## 工作原理

战斗中的光环数据对插件是 secret —— 读不到、也不能比较，所以"把带 debuff 的怪加总成一个数"
在客户端里无法实现。进度条 / 格子是这个限制下能表达比例的极限做法：颜色的含义由客户端判定
（插件永远不知道答案），几何的长短由插件自己决定，两者叠加 ⇒ 用长度 / 面积读比例。

实现方式（与同一思路的社区插件一致）：

1. 每只符合条件的怪占一段属于插件自己的矩形（自己的 Texture，可随意读写）
2. 给每只怪建一个原生 `AuraContainer`，声明"这个槽只接受【我（或我的宠物）上的】法术 N"，
   显示与否完全由客户端的光环系统判定
3. 插件只观察自己的红段出现或消失 ⇒ 把"计算"降级成"看颜色"

因此：不要读 `AuraButton` 的成员、不要监听 `UNIT_AURA`、不要把容器锚到别人的 Frame 上。

## 常见问题

**屏幕上看不到任何东西**
先 `/dg spell 1943,703`（没设置法术时插件处于待机）；再确认"只在战斗中显示"（默认开），
以及范围内至少有 2 只怪（`/dg bar min 1` 可以改成一只也显示）。

**一个红段都不出现**
`/dg verify` 脱战后逐只对照；或 `/dg debug on` 打一场，看是否有 `AddAuraSlot` 失败、
`initializeFrame` 取不到填充贴图之类的输出。

**拖不到想要的位置**
`/dg unlock` 后在屏幕上直接拖黄框；黄框左上角就是坐标原点。锁定后插件不注册鼠标事件，
不会挡住别的插件。

**图形界面右边一片空白**
`/reload` 后再 `/dg`；仍然空白就 `/dg diag`，看最后一行"界面: 窗口=… · 当前页=… · 行数=…"：
行数为 0 = 界面没建成，当前页可见行为 0 = 页名失效。界面建页或刷新出错时会把 Lua 报错
直接打到聊天框。

**想只算正在跟我打的怪**
`/dg engaged threat`。副本 / PvP 里威胁值受限时，单只怪会自动退回"在战斗中"判定。

## 技术说明（维护者）

- 只用文档核实过的原语：`UnitExists` / `UnitCanAttack` / `UnitIsDead` / `UnitAffectingCombat` /
  `CheckInteractDistance` / `UnitDistanceSquared` / `UnitThreatSituation`；两个可能受限的调用
  （距离、威胁）必须 `pcall` + `issecretvalue` 预判，失败时退回更保守的判据，绝不放宽范围。
- 尺寸 / 颜色只能在 `initializeFrame` 里定一次；改这些参数走 `RebuildRecords()` 整批退役重建
  （立即生效，不用 `/reload`）。次序变化只需重新 `SetPoint`，不必重建。
- 段数只有一种语义：`BarCount()` = 当前怪数。不要再引入第二套段数来源。
- 少于 `BarMin()` 只怪时走 `HideAllVisuals()` 提前返回：条、底槽、刻度线、以及客户端那侧的
  红块容器都要一起停用。
- 没设置监控法术时刷新路径整体提前返回（待机）；`RebuildRecords()` 里也要挡一道 —— 有些命令
  会先重建再刷新。
- 锚点会被"解锁拖动"撑大，所以锚点上的所有贴图都必须用显式坐标 + `SetSize`，不能用
  `SetAllPoints` 之类跟着锚点走的锚定方式。
- 界面（`DotGridUI.lua`）动任何东西都必须走 `API.Run("命令字符串")`，不要在界面里直接写存档
  或直接刷新 —— 否则会出现"界面改了但插件不知道"的漂移。
- 界面里带说明文字的行：控件占 -4..-24，说明从 -26 起画（行高按 `FontString:GetStringHeight`
  自动撑开）。界面是懒建的：第一次 `/dg` 才建页 / 建行。

## 本地化

插件源码里的文案**以中文原文作为键**，语言表放在 `Locales/` 下：

```
Locales/enUS.lua    英文（enUS / enGB 客户端加载）
```

- 没有对应语言的文件时，直接显示中文原文 —— 加一种语言不需要改任何代码
- 加语言：复制 `Locales/enUS.lua` 改成目标语言代码（如 `deDE.lua`），
  把 `GetLocale()` 的判断和翻译值改掉，再在 `DotGrid.toc` 的文件列表里加一行
- 键必须与源码里的中文原文**逐字一致**（含空格与标点），否则那一条不生效
- 存档里的数据（配置档名、法术 ID）不翻译；只有界面与聊天文案走语言表。
  「默认」档在英文客户端显示为 `default`，但存档里仍然是「默认」，不会串档

欢迎提交其他语言的翻译。
