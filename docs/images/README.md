# Screenshots

This folder holds the pictures used by the project READMEs.

Drop a still image at `docs/images/preview.png` (and optionally a recording at
`docs/images/preview.gif`, which shows the bar following the mob count much better), then uncomment
the corresponding line near the top of `README.md` and `README.zh-CN.md`:

```markdown
![DotGrid](docs/images/preview.png)
```

A useful screenshot shows a pack of mobs with several of them carrying the watched debuff, so both
the white and the red segments are visible, plus the settings window or `/dg diag` output in a second
image if you want to document the diagnostics. Keep files under ~1 MB; PNG for stills, GIF or MP4
for recordings.
